# LifeOs · 学习工作台

考研与学期生活的一站式管理面板：任务、健身、体重、复盘、每日激励，一个单文件网页全部搞定。

🔗 **在线访问：<https://meng-p7.github.io/LifeOs/>**

## 功能

### 📋 总览
- 考研倒计时：剩余天数大字 + 备考进度条，考试日期和名称可在「设置」中修改
- 今日激励语：每天一句不重复，也可手动「换一句」
- 今日到期待办、今日训练状态、本周完成度，一屏看完

### ✅ 任务
- 按科目管理：机械设计、工程流体力学、机械控制工程、金属工艺学、机械精度设计、计算方法、热工基础、考研英语、考研数学（科目可在设置中自由增删）
- 截止日期 + 优先级，逾期、今天到期自动高亮提醒
- 进行中 / 今天 / 本周 / 逾期 / 已完成多维筛选，按科目过滤

### 🏋️ 健身
- 周二 / 四 / 六训练计划：6 个动作（俯卧撑、单臂哑铃推举、单臂哑铃划船、哑铃深蹲、哑铃弯举、平板支撑）共 18 组逐组打卡
- 训练备注、历史记录、本月训练天数、当前 / 最长连续训练统计

### ⚖️ 体重
- 每日体重一键记录，显示较昨日变化
- 30 天趋势折线图、最近 10 条历史记录

### 📊 复盘
- 本周每日完成任务柱状图
- 科目完成度分布
- 最近 8 周健身打卡热力图（计划训练日有标识）

## 使用方式

**在线版**：访问 <https://meng-p7.github.io/LifeOs/>，推荐 Chrome / Edge，手机浏览器同样可用（布局已适配）。

**本地版**：下载仓库中的 `index.html`，双击即可打开，无需安装任何东西、无需联网。

## 数据说明

- 所有数据只保存在本机浏览器的 localStorage，不上传任何服务器；线上版与本地版数据互不相通
- 「导出备份」可随时下载 JSON 备份文件；换电脑或换浏览器时用「导入」恢复
- 未内置计时功能——与手机端番茄钟类 App 错开，避免学习时间重复记录

## 技术

- 单个 HTML 文件，零构建、零依赖（字体走 CDN，离线时自动回落系统字体）
- 原生 HTML / CSS / JavaScript，Canvas 动态背景，localStorage 持久化
