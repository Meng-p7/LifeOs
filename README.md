# LifeOS · 个人生活操作系统

考研学习、健身增重、日程管理、复盘统计的一体化工作台。
核心理念：**打开 LifeOS，就知道今天最重要的事是什么、下一步做什么、离长期目标还有多远。**

🔗 **在线访问：<https://meng-p7.github.io/LifeOs/>**

## 功能模块

### 🏠 今日（行动中心）
- 问候语 + 日期，距考试倒计时（名称/日期可配置，备考进度条按真实数据计算）
- 今日重点任务（最多 3 项）、今日完成率环、待完成与逾期统计
- 今日时间轴：课程/学习/健身/休息块，当前时间线标记，一键完成、快速编辑
- 核心数据一览：今日学习、本周任务完成率、当前体重（含 7 日均值）、本周训练、今日复盘状态
- 数据同步状态芯片（本地模式 / 同步中 / 已同步 / 离线 / 失败，真实状态不伪装）

### ✅ 任务
- 科目、截止日期、优先级、预计时长；逾期与今天到期自动高亮
- 进行中 / 今天 / 本周 / 逾期 / 已完成 / 全部多维筛选 + 科目过滤
- 软删除（墓碑机制），编辑、完成、删除均有操作入口

### 📖 学习（番茄钟）
- 自建每日事项：添加、重命名、删除，默认预置「背单词 / 数学刷题 / 专业课复习」（可改可删）
- 点「开始」即计时：大时钟实时跳动，支持暂停 / 继续 / 结束并记录 / 丢弃；同时只计一件事，刷新页面不丢失
- 今日时长环形图：按事项占比，中心显示今日总计
- 每日学习时长：最近 14 天柱状图 + 本周/近 14 天汇总

### 🏋️ 健身与增重
- 训练计划可配置：每周训练日自选、动作增删改（名称/组数/次数/部位/要点）、组间休息时长
- 今日打卡：逐组打勾、主观难度 RPE、训练备注，18 组全完成有庆祝提示
- 统计：本月/本周训练天数、当前与最长连续
- 体重：每日记录、较昨日变化、30 天趋势折线图、7 日平均（平滑日常波动）、目标体重、历史可删
- 饮食：餐次 + 食物 + 热量手动记录，每日汇总与目标对比（热量为输入/估算值，非精确测量）
- 训练历史：最近 14 次的完成度、RPE、备注

### 📅 日程
- 日视图时间网格（06:00–24:00）+ 周视图，时间块支持新建 / 编辑 / 删除 / 标记完成
- 时间重叠检测：保存前提醒，确认后可保留有意安排的重叠
- 未安排任务一键排入时间轴；任务与时间块可互相关联

### 📊 复盘
- 每日复盘：真实数据汇总（完成任务/学习时长/训练/体重）+ 进展/问题/明日重点，可一键生成草稿后编辑
- 每周复盘：本周任务完成率、各科目时长、训练次数、体重变化、计划与实际差异、调整事项
- 历史复盘独立保存，生成新记录不覆盖旧记录

### ⚙️ 设置
- 考试名称与日期、训练计划、体重/热量目标、主题（浅色/深色/跟随系统）
- 数据导出 / 导入（JSON）、v1 旧数据恢复、清空数据（二次确认）

## 使用方式

**在线版**：访问 <https://meng-p7.github.io/LifeOs/>，推荐 Chrome / Edge，手机浏览器布局已适配（底部导航）。

**本地版**：下载 `index.html` 双击打开，无需安装、无需联网。

**多设备同步**：数据默认保存在浏览器本地。已内置 Supabase 云同步（代码就绪）：按 `docs/SUPABASE_SETUP.md` 第 3 节建表，然后在「设置 → 云同步」填写项目地址和 Publishable Key 即可实现电脑与手机同步；首次登录自动合并本地与云端数据，不会被空云端覆盖。

## 数据说明

- 数据存于浏览器 localStorage，不上传任何服务器；顶栏同步芯片真实反映同步状态
- 导出备份随时可下载；换设备用「导入」恢复；v1 老数据首次打开自动迁移并自动备份原数据
- 删除为软删除（墓碑），防止已删记录被其他设备同步回来
- 未内置 AI 功能；所有统计数字均来自真实记录，无演示数据

## 工程结构

```
LifeOs/
├── index.html            # 构建产物（单文件，Pages 部署/本地双击都用它）
├── src/                  # 源码（修改这里）
│   ├── template.html     # HTML 骨架
│   ├── styles.css        # 设计系统（深浅主题、组件、响应式）
│   └── js/
│       ├── store.js      # 数据模型 v2 + v1 迁移 + 旧数据备份
│       ├── ui.js         # DOM/弹窗/确认/Toast/主题
│       ├── charts.js     # SVG 图表（折线/柱状/进度环/热力图）
│       ├── sync.js       # 同步状态机 + 记录级合并 + CloudAdapter 接口
│       ├── timer.js      # 专注计时引擎（持久化、防重复累计）
│       ├── views/        # today/tasks/study/fitness/schedule/review/settings
│       └── app.js        # 路由、启动、导入导出、动态背景
├── tools/build.js        # 零依赖构建：src → index.html
├── supabase/migrations/  # 云端同步 schema 与 RLS（待配置）
└── docs/SUPABASE_SETUP.md
```

**本地开发**：修改 `src/` 后执行 `node tools/build.js` 重新生成 `index.html`，刷新浏览器即可。

## 无障碍与适配

- 深浅双主题、`prefers-reduced-motion` 降级
- 键盘可达（焦点样式、Enter/Space 操作）、弹窗焦点管理与 Escape 关闭
- 触控目标 ≥ 44px、删除按钮常驻不依赖悬停、手机端无横向溢出
- 高风险操作（删除、导入、清空）均有确认；空数据 / 加载 / 失败均有明确状态
